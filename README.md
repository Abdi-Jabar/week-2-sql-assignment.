# Week 2 Assignment: Introduction to SQL

## Project Overview
This project demonstrates my understanding of basic SQL queries using the sales database.

## Learning Objectives
- Selecting specific columns from tables.
- Filtering records using WHERE.
- Sorting records using ORDER BY.
- Limiting query results using LIMIT.
- Retrieving information from different tables.

## Assignment Questions

### Question 2: Find Orders in Process
Retrieved orderDate, requiredDate, and status from the orders table for orders with the status In Process.

### Question 3: Find Sales Representatives
Retrieved firstName, lastName, and email from employees whose job title is Sales Rep.

### Question 4: Retrieve Office Information
Retrieved all columns and records from the offices table.

### Question 5: Retrieve the Five Cheapest Products
Retrieved productName and quantityInStock for the five products with the lowest buyPrice.
